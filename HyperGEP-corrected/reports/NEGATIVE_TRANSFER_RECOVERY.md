# 负迁移实验追溯

项目有两个数据集的 Raw_Fold_Results.csv、Quantitative_Transfer_Metrics.csv、可视化脚本、图稿和部分日志。两数据集均有五个折，分别有 165 与 45 个可用折级 PCC 值。原始训练实现、完整配置、种子、训练/test 样本成员与 checkpoint 关联尚未恢复。项目相邻目录还有基线日志和结果压缩包，以及多个解释性阶段的脚本。单凭相关名称和折编号无法校验监督谱系。

已逐性状重算三种模型的 PCC 均值与相对 STL 的差值。两个历史汇总的最大绝对误差小于 2e-16，数值同补充数据 1 的转移表一致。历史表中早期耦合降低 PCC 的性状在 MaizeGEP 为 8/11，在 G2F 为 2/3。HyperGEP 提高 PCC 的性状分别为 10/11 与 2/3。这些是旧表的复算，结论依赖未验证的旧数据划分。

修正版重新实施 STL、共享环境/SNP 编码及融合的 MTL、独立分支加 Meta-Fusion。三种方法共享外折、有效标签规则和尺度拟合原则。比较脚本按数据哈希、协议、trait、fold、seed 和样本 ID 严格校验配对。训练日志记录参数量和耗时。历史 Delta PCC 未参与模型训练。三种实现完成 CPU 合成单折，正式同折比较仍待重训。
