# Experiments and resources

The named modules share flags for `--config`, `--dataset`, `--variant`, `--trait`, `--fold`, `--seed`, `--device`, `--data-dir`, `--output-dir`, `--resume` and `--dry-run`. A multi-trait model with one requested output trait still fits all its configured source branches. An independent branch or baseline can train only the requested trait. Fold numbering is zero-based. For independent workers assign distinct folds, use separate GPU ordinals when authorized and retain the common output root. The runner reads available device memory at launch when supported.

Record CV permits repeated genotypes and environments across folds. Choose `--split genotype`, `environment`, `site` or `genotype_environment` to evaluate the respective held-out group. LOEO always holds out a complete environment, and only considers environments meeting the predeclared minimum count. Inner grouped CV retains the same grouping unit. GroupKFold's deterministic group allocation does not depend on seed in the tested scikit-learn implementation.

GBLUP_Proxy is linear genomic kernel ridge on fold-scaled SNPs with a fixed penalty. Classical regressors use aligned SNP and environment features. Historical baseline settings require line-by-line provenance before treating a corrected comparator as equivalent. Run the independent PyTorch topology reconstructions using the genomic comparator entry point. DeepGS uses the documented eight width-18 kernels, width-4 max pooling, dense sigmoid layer and MAE. DNNGP uses the published three-convolution, normalization, dropout, flattening and dense topology. Its channel widths (16, 24, 32), width-5 kernels and fixed budget are new defaults. Both train independently on SNPs under the corrected folds. They need formal comparison and implementation review before replacing historical Fig. 4c. [DNNGP implementation](https://github.com/AIBreeding/DNNGP), [DeepGS implementation](https://github.com/cma2015/DeepGS)

With five inner folds and outer refit, each of five outer folds fits six base branches per trait. For 11 traits this is 330 branch fits and five Meta fits per seed and full-model run. For three traits it is 90 branch fits and five Meta fits. Early-coupled MTL trains one shared network per outer fold. Each ablation and K candidate increases the budget. LOEO costs up to six fits per trait per eligible environment. Record parameter counts and measured epoch times using training logs. Reference graph KNN initially computes distances in blocks over unique training IDs, and the environment encoder recomputes reference representations in each training step. SNP-graph ablations and dense baselines warrant an independent memory measurement.

Full evaluation is invoked with `DATA_DIR=data OUTPUT_DIR=artifacts/corrected DEVICE=cuda:0 bash scripts/run_full.sh`. Freeze inputs and review the release blockers before running the full matrix. All experiments use explicit run manifests for run reuse and attribution.
